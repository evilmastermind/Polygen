# Operators Reference

## Alternation: `|`

Use `|` to choose between alternatives in a production.

```text
S ::= red | blue | green;
```

## Epsilon: `_`

`_` produces no output.

```text
S ::= hello _ world;
```

This is mainly useful inside optional and recursive productions.

## Concatenation: `^`

`^` removes the space that would normally be inserted between adjacent output tokens.

```text
S ::= hello ^ "!";
```

This yields `hello!` instead of `hello !`.

## Capitalization: `\`

`\` capitalizes the next emitted terminal output.

```text
S ::= \ hello ^ "!";
```

This yields `Hello!`.

## Optional Groups: `[ ... ]`

Square brackets represent an optional subgrammar.

```text
S ::= hello [ world ];
```

The optional body can either produce its content or disappear as epsilon.

## Mobile Groups: `{ ... }`

Curly braces mark mobile groups. During preprocessing, mobile atoms may be permuted with each other inside the same sequence.

```text
S ::= the quick {fox} jumped over the lazy {dog};
```

## Unfold: `>`

`>X` unfolds a non-terminal or group into a subgrammar form during compilation.

```text
S ::= >Phrase;
Phrase ::= hello | world;
```

The current port rejects cyclic unfold chains such as `S ::= >S;`.

## Lock: `<`

`<X` locks a target against unfolding.

Use this when you need the non-terminal or group to remain intact instead of being unfolded by surrounding syntax.

## Selection Helpers

Selection syntax is documented together with label semantics in [Labels and Scoping](/docs/guides/labels-scoping), because those operators depend on the active label environment.
